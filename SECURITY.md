# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in VoxForm, please report it responsibly rather than opening a public issue.

**Contact:** contact@voxform.co.uk

Please include:
- A description of the vulnerability
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept code

We'll aim to acknowledge reports within 48 hours and keep you updated as we investigate and fix the issue. We ask that you give us reasonable time to address the vulnerability before any public disclosure.

## Scope

This repository contains the VoxForm website codebase. Note that credentials, API keys, and other secrets are never stored in this repository — if you find what appears to be a leaked credential, please report it immediately as it would be treated as a critical issue.

## Supported Versions

As this is a live production website, only the `main` branch is actively maintained and monitored for security issues.
